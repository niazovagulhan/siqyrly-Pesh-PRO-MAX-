# 🍕 СИҚЫРЛЫ ПЕШ PRO MAX 3D

5-сыныпқа арналған математика ойыны: **бөлімдері әртүрлі жай бөлшектерді қосу және азайту**. Қазақша интерфейс, анимациялық пеш, кесінділермен боялған пицца, үш деңгейдің әрқайсысында 10 есеп, мұғалім панелі, онлайн рейтинг және Excel (.xlsx) экспорты.

## 1. Жоба файлдары

```text
siqyrly-pesh-pro-max-3d/
├── server.js                 # Сервер және тапсырмалар тексеруі
├── package.json              # Node.js арқылы іске қосу
├── offline_demo.html         # Серверсіз жеке құрылғыда ойнайтын HTML
├── .env.example              # Баптау үлгісі
├── public/
│   ├── index.html            # Ойын және мұғалім интерфейсі
│   ├── styles.css            # 3D-стильдегі пеш, анимациялар, бейімделгіш дизайн
│   └── app.js                # Пицца, тапсырмалар, таймер, QR, рейтинг
├── tests/game.test.js        # Автоматты тексеру
└── data/                     # Оқушы нәтижелері осы жерде сақталады
```

**Құрылғыда бірден сынау:** `offline_demo.html` файлын браузерде ашсаңыз, барлық 30 тапсырмасы бар жеке ойын жұмыс істейді; бірақ бұл нұсқада QR, мұғалім панелі, оқушылар арасындағы онлайн рейтинг болмайды. Толық нұсқа үшін серверді қосыңыз.

**Артық npm пакеттері жоқ**: Node.js 18 немесе жоғары нұсқасы жеткілікті. Пеш — CSS перспективасы арқылы жасалған **3D-стильдегі анимация**, бөлек 3D моделін орнату талап етілмейді.

## 2. Ноутбукте немесе компьютерде ашу

1. ZIP файлын толық шығарыңыз.
2. [nodejs.org](https://nodejs.org) сайтынан Node.js-тің қолданыстағы LTS нұсқасын орнатыңыз.
3. `siqyrly-pesh-pro-max-3d` қалтасынан терминал/PowerShell ашыңыз.
4. `.env.example` файлын `.env` деген атаумен көшіріңіз және **TEACHER_PASSWORD=** жолына өзіңіз ойлап тапқан **кемінде 10 таңбалы құпиясөзді** қойыңыз.
5. Терминалда `node server.js` немесе `npm start` деп теріңіз.
6. Chrome/Edge браузерінде **http://localhost:3000** ашыңыз.
7. Оқушы аты-жөнін, сыныбын, деңгейді көрсетіп, ойынды бастаңыз.

**Windows PowerShell:** `Copy-Item .env.example .env` → `.env` файлын Блокнотпен ашу → құпиясөзді ауыстыру → `node server.js`.

> Тек `index.html` файлын екі рет басу жеткіліксіз: рейтинг, есепті серверде тексеру, QR және Excel функциялары үшін `node server.js` жұмыс істеуі тиіс.

## 3. Мұғалім панелі

«👩‍🏫 Мұғалім» батырмасын басыңыз. Құпиясөз — `.env` файлында **өзіңіз енгізген** `TEACHER_PASSWORD` мәні. Мұғалім:
- деңгейді ашады/құлыптайды;
- 0–240 минут уақыт қояды (0 — шектеусіз);
- жаңа есеп қосады, өзгертеді, өшіреді;
- нәтижені ұпайы бойынша кему ретімен көреді;
- **Excel (.xlsx)** форматына шығарады;
- жаңа сабақ үшін бөлме кодын ауыстырып, бұрынғы нәтижені тазалайды;
- өзінде HTTPS сілтемесі бар пеш суретін қажет болса орната алады.

Оқушылардың нәтижелері `data/game.json` файлында сақталады. Бұл файлды сақтық көшірмеге алып отырыңыз. Оқушы деректерін қажет болғанда жойыңыз.

## Байланыс телефонын өзгерту

Ойынның **жоғарғы жағында** «Ниязова Гулхан Қалдыбекова · 📞 87076525807» көрсетіледі. Телефон сілтемесін басқанда құрылғының қоңырау шалу интерфейсі ашылуы мүмкін.

- **Онлайн серверлік нұсқада**: «Мұғалім» → құпиясөз → «⚙️ Ойын параметрлері» → «📞 Байланыс телефоны» жолын өзгертіңіз → «💾 САҚТАУ». Нөмір `data/game.json` ішінде сақталып, сайтқа қосылған оқушыларда да жаңарады.
- **Офлайн нұсқада**: жоғарғы бөліктегі «✏️ Телефонды өзгерту» батырмасын басыңыз. Жаңа нөмір тек осы браузердің `localStorage` жадында сақталады. Браузер деректері тазаланса, бастапқы нөмір қайта көрінеді. Бұл өзгеріс басқа телефондарға автоматты берілмейді.
- Нөмір 10–15 цифрдан тұруы тиіс (басында `+` болуы мүмкін). Өзгерту үшін кодты қолмен түзетудің қажеті жоқ.

## 4. Телефондардан QR арқылы кіру

**Маңызды:** `localhost` сілтемесі тек мұғалім ноутбугінде ашылады. Оны телефонға QR етіп көрсету арқылы басқа телефондардан кіре алмайсыз.

Ойын барлығына ашық болуы үшін сайтты **Node.js серверін қолдайтын, HTTPS мекенжайы және тұрақты файл сақтау орны бар** хостингке орналастырыңыз:

1. Жобаны жеке Git репозиторийіне жүктеңіз. `.env` және `data/game.json` жүктемеңіз.
2. Render, Railway немесе басқа Node.js хостингінде веб-сервис жасаңыз (хостинг мүмкіндіктері мен тарифтерін нақты тексеріңіз).
3. **Start command:** `npm start` (қажетті build жоқ).
4. **Environment variables:** `TEACHER_PASSWORD=өз-құпиясөзіңіз`, `PUBLIC_URL=https://сіздің-сайтыңыз`.
5. Оқушы нәтижесі өшпеуі үшін хостингте **persistent disk/volume** қосып, `DATA_DIR` параметрін сол сақтау орнына көрсетіңіз; көптеген уақытша серверлер файлдарды қайта іске қосылғанда өшіреді.
6. Сайт жарияланған соң «Мұғалім» бөліміне кіріңіз: қатысу сілтемесі мен QR-код пайда болады.
7. QR суреті үшін сыртқы `api.qrserver.com` қызметі қолданылады. Қызмет қолжетімсіз болса, мұғалім қатысу сілтемесін көшіріп бере алады.
8. Проекторда «🏆 Қатысушылар рейтингі» бетін ашыңыз. Оқушылар телефондарынан орындаған сайын тақтада нәтиже жаңарады.

**Бір мезгілде 50+ қатысушы:** сервер Node.js HTTP + Server-Sent Events (SSE) архитектурасымен жасалды. Автоматты тестте 55 қатар қатысушының тіркелуі тексеріледі. Қоғамдық желіде тұрақты жұмыс істейтіні сервердің ресурсына және хостинг шектеуіне байланысты; нақты сыныпта алдын ала сынаңыз.

## 5. Тапсырма түрлері

Әр есеп төрт қадаммен беріледі:
1. ЕКОЕ табу.
2. Ортақ бөлімге келтіру.
3. Жауаптың бір түрін орындау: 4 жауаптан таңдау, бөлшекті енгізу, пиццаны сүйреуге дайындау, сәйкестендіру, қатені түзету.
4. Пиццаны пешке сүйреп салу немесе «Пиццаны пешке салу» батырмасын басу.

Деңгейлер: **I — 10 ұпай**, **II — 15 ұпай**, **III — 20 ұпай** (бір дұрыс есепке). Пицца SVG арқылы математикалық ауданға сәйкес боялады. Бөлшектер дәл рационал сандармен тексеріледі, қаласаңыз қысқармаған эквивалент бөлшекті де енгізуге болады.

## 6. Тексеру

Терминалда `npm test` теріңіз. Тест жеке уақытша деректер қалтасын пайдаланады; өз оқушыларыңыздың деректерін өзгертпейді. 30 дайын есеп, тіркеу, бағалау, мұғалімнің құпиясөзі, параметрлер, тапсырмаларды редакциялау, экспорт және жаңа сабақ тексеріледі.

## 7. Маңызды шектеулер

- Ойын коды **дайын**, бірақ сіздің интернет-сайтыңызға **жарияланып қоймаған**. Онлайн QR тек жариялағаннан кейін қолданылады.
- Хостинг сервистері мен олардың тарифтері үшін бөлек аккаунт ашу қажет болуы мүмкін.
- QR суреті үшін Интернеттегі сыртқы сервистің қолжетімді болуы керек; QR істемесе, URL жұмыс істейді.
- Ұзақ мерзімді үлкен көлемдегі деректер үшін JSON орнына PostgreSQL және серверлік резервтік көшіру жүйесін енгізген жөн.
- Ойын 3D визуал әсерін CSS-пен жасайды; бұл Three.js көлемді 3D модель емес.
