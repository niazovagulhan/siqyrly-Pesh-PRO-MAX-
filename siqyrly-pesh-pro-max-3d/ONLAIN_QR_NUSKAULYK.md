# СИҚЫРЛЫ ПЕШ PRO MAX 3D — QR арқылы онлайн жариялау

Бұл ZIP интернетке жариялауға **дайындалған жоба**, бірақ сайт әзірге интернетте орналастырылған жоқ. 
Нақты жұмыс істейтін QR-код тек сайттың HTTPS адресі пайда болған соң шығады.

## 1. GitHub-қа файлдарды жүктеу
1. ZIP архивті компьютерге жүктеп, ашыңыз.
2. https://github.com сайтына өз аккаунтыңызбен кіріңіз.
3. New repository → Name: `siqyrly-pesh-pro-max-3d` → Create repository.
4. **Add file → Upload files** таңдаңыз.
5. ZIP-тің ішіндегі `siqyrly-pesh-pro-max-3d` бумасындағы файлдар мен `public`, `tests`, `data` бумаларын репозиторийдің **түбіріне** жүктеңіз. Тек ZIP-тің өзін жүктемеңіз.
6. `Commit changes` батырмасын басыңыз.
7. `.env` немесе `data/game.json` файлдарын жарияламаңыз.

## 2. Render-де сайтты іске қосу
1. https://render.com → тіркелу/кіру.
2. Dashboard → New → Blueprint; GitHub репозиторийін қосыңыз.
3. Жобаның `render.yaml` файлын таңдаңыз.
4. `TEACHER_PASSWORD` мәніне 10 таңбадан ұзын, өзіңіз ғана білетін құпиясөз жазыңыз.
5. Жоба іске қосылғанда Render беретін `https://...onrender.com` мекенжайын ашыңыз.

Альтернатива: Render → New → Web Service → репозиторий → Node → Build command `npm install` → Start command `npm start` → Environment `TEACHER_PASSWORD=...`.

## 3. Нағыз QR-кодты алу
1. Жарияланған HTTPS сайтты ашыңыз.
2. Оң жақтағы `👩‍🏫 Мұғалім` батырмасын басыңыз.
3. Құпиясөзіңізді енгізіңіз.
4. Мұғалім панеліндегі **QR-код және қатысу сілтемесі** бөліміне өтіңіз.
5. QR-кодты проекторда көрсетіңіз. Оқушылар оны телефон камерасымен ашады.
6. `🏆 Қатысушылар рейтингі` бөлімін проекторда ашып, ұпайларды қадағалаңыз.

Жоғарғы жағында **Ниязова Гулхан Қалдыбекова — 87076525807** көрсетіледі.
Телефон нөмірін Мұғалім → Ойын параметрлері арқылы өзгертуге болады.

## 4. Маңызды: оқушы нәтижелерін сақтау
Render-дің **Free** серверінде сақтау орны тұрақты емес: сервис өшіп/қайта іске қосылғанда нәтиже жоғалуы мүмкін.
Бұл жоспар жылдам сынауға арналған. Әр сабақтан кейін Excel файлын жүктеп алып сақтаңыз.
Нәтижені тұрақты сақтау үшін ақылы persistent disk/volume не деректер базасын қосу қажет.
Қауіпсіздік үшін оқушылар толық аты-жөнінің орнына қысқартылған есімін қолдана алады.

## 5. Егер QR жұмыс істемесе
- Домен `https://` деп басталатынын тексеріңіз.
- Телефоннан сілтеменің өзін ашып көріңіз.
- Ойынның мұғалім бетін жаңартыңыз.
- Интернет болмаса, оқушылардың жеке телефондарынан сайт ашылмайды.
- `localhost:3000` тек сол компьютерде жұмыс істейді, ол жалпыға ортақ QR емес.
